# Information Confrontation Technology

本仓库整理的是南开大学《信息对抗技术》课程资料与实验成果，原始目录名为“信息对抗技术”。

## 内容概览

- `信息对抗技术PPT/`：课程课件，覆盖信息对抗的产生与发展、内涵与模型、主要能力、主要样式、安全漏洞、风险分析、网络攻击与网络防护等主题。
- `第一次实验/` 至 `第八次实验/`：课程实验报告、截图、实验要求和过程材料。
- `第九次实验/`：木马基本功能实现相关实验材料，包含报告、截图和 `RemoteLab/` C++ 实验工程。
- `第九次实验/RemoteLab/`：受控远程命令实验项目，包含 C++17 源码、CMake 配置、Visual Studio 构建脚本和独立说明文档。

## RemoteLab 说明

实验九——木马基本功能的实现——`RemoteLab` 是课堂/虚拟机环境下使用的受控实验工程，用于演示远程命令、文件列表、文件上传下载、截图和延时关机/取消关机等实验要求。

该项目已有独立的 `README.md`，并通过其目录内的 `.gitignore` 排除了 `build/`、`.obj`、`.exe` 等构建产物。

## 说明

本仓库用于课程资料归档、实验复现和学习记录。涉及网络与系统操作的实验内容应仅在授权的本地环境、课堂实验环境或虚拟机中运行。
